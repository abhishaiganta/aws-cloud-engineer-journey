# Week 3: Compute (EC2)

This week I deployed PropertyLite, the same Flask app from Week 0, onto a real EC2 server. I launched an Amazon Linux 2023 t3.micro instance called `property-api-01` in us-east-1 and left the storage at the default 8 GiB. I made a key pair called `training-key`, which is the only way to SSH into the server, and I ran `chmod 400` on it because SSH refuses a key file that other users can read. For the security group, I allowed SSH (port 22) only from My IP so nobody else can try to log in, and I opened port 8080 to anywhere because that's the port PropertyLite runs on. I also pasted a user data script, which runs once on the first boot. It installs Python and Flask, writes `app.py` and the sample CSV into `/opt/property-api`, and starts the app. Once the status checks showed 3/3 passed, I got the public IP from the AWS CLI and tested it with curl. `/health` returned `{"status":"ok"}` and `/properties/R100234` returned the Sacramento listing (screenshot in `curl-output.png`). I also SSHed in and confirmed `python3 app.py` was running. After that, I took an EBS snapshot of the root volume (`snapshot.png`). A new volume made from that snapshot would be an exact copy of the disk as it was when the snapshot was taken, so it works as a backup. When I was done, I terminated the instance, checked that its volume was gone, and deleted the snapshot so nothing was left running.
